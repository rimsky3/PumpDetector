## Критерій

- split_pot3: місяців ≥ 20 млн краще за base 3 з 6; обидві половини так; загальний PF ≥ base ні → **НЕ виконано**
- split_pot3_x: місяців ≥ 20 млн краще за base 4 з 6; обидві половини так; загальний PF ≥ base ні → **НЕ виконано**
- split_pot5: місяців ≥ 20 млн краще за base 4 з 6; обидві половини так; загальний PF ≥ base так → **ВИКОНАНО**
- only_pot3: місяців ≥ 20 млн краще за base 2 з 6; обидві половини ні; загальний PF ≥ base ні → **НЕ виконано**
- only_pot3_x: місяців ≥ 20 млн краще за base 5 з 6; обидві половини так; загальний PF ≥ base так → **ВИКОНАНО**
- only_pot5: місяців ≥ 20 млн краще за base 3 з 6; обидві половини ні; загальний PF ≥ base ні → **НЕ виконано**
